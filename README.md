# tg_budget_bot

Телеграм-бот для учёта личных расходов в Сербии (валюта RSD). Принимает скрин банковской транзакции, текстовое описание расхода или просто сумму — и пишет запись в Google Sheets.

## Как пользоваться

**Скрин транзакции** (Raiffeisen RU, Freedom Bank KZ) — бот распознаёт дату, мерчанта, сумму и предлагает категорию через Claude API. Можно прислать альбом из нескольких скринов сразу — все распознаются и добавляются в очередь подтверждения.

**Текст** — `Кофе 500` или `Wolt 1200 RSD еда`, тоже через Claude.

**Просто сумма** — `500` или `1200.50`: без Claude, сразу предлагает выбрать категорию из списка.

Для каждой транзакции — карточка с датой/мерчантом/суммой/категорией и кнопки:
- ✅ **Добавить** — записать как есть
- ✏️ **Категория** — выбрать другую категорию (выбор сразу сохраняет, без повторного подтверждения)
- ❌ **Пропустить** — не записывать

Если мерчант уже встречался раньше — категория подставляется автоматически и транзакция сохраняется без подтверждения. Если новый мерчант похож на уже известный (например, другой ID того же магазина — `Maxi 1234` vs `Maxi 5678`), бот один раз спросит, тот ли это мерчант, и запомнит правило на будущее (🔗 Да, это ... / Только сейчас).

Команды:
- `/start` — приветствие
- `/repair` — починить формулы в листе «суммы по месяцам», если они сбились после ручной правки таблицы
- `/cancel` — отменить текущий ввод

## Хранилище — Google Sheets

- **транзакции 2026** — построчная история, новые записи вставляются сверху (свежие первыми)
- **суммы по месяцам** — сводка по категориям и месяцам на формулах, колонка на новый месяц создаётся автоматически
- **правила мерчантов** — подтверждённые склейки похожих мерчантов (создаётся автоматически при первом использовании)

## Архитектура

```
bot.py                    # entry point, ConversationHandler, коллбэки кнопок
config.py                 # токены, список категорий, названия месяцев
keyboards.py               # инлайн-клавиатуры и текст карточки транзакции
handlers/
  photo.py                # обработка скринов (включая альбомы)
  text.py                 # обработка текста и голых сумм
services/
  claude.py               # распознавание транзакций через Claude API
  sheets.py                # чтение/запись Google Sheets
  categorize.py             # сопоставление мерчант → категория (точное + по правилам)
  merchant_grouping.py     # эвристика группировки мерчантов по названию сети
scripts/
  find_merchant_groups.py  # разовый скрипт: найти потенциальные группы дублей в истории
```

## Запуск локально

```
pip install -r requirements.txt
cp .env.example .env   # заполнить своими значениями
python bot.py
```

Переменные окружения (`.env`):

| Переменная | Назначение |
|---|---|
| `TELEGRAM_TOKEN` | токен бота от BotFather |
| `ANTHROPIC_API_KEY` | ключ Claude API |
| `SPREADSHEET_ID` | ID таблицы (из ссылки на Google Sheet) |
| `GOOGLE_CREDENTIALS_JSON` | JSON сервис-аккаунта Google (целиком, одной строкой; raw или base64) |

## Деплой

`Procfile` (`worker: python bot.py`) — процесс-воркер, деплой через push в `master` на подключённый сервис (переменные окружения задаются там же, не в репозитории).
